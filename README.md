> "My grandmother said, 'If you can't explain why you're angry in one sentence, you're not angry about that thing' — and it's saved me from sending a hundred messages I couldn't take back."

## How it works

`main.py` holds the entry sentence as a constant, asserts it is non-blank, a single line, and 1–200 characters, then writes it as UTF-8 bytes with no trailing newline to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
